# OnyxPDF

**50 free PDF & image tools that run 100% in your browser.**

Live: **https://onyxailabs.github.io/onyxpdf/**

Most online PDF sites work the same way: you upload your file to their server, they process it, and you download the result. Your contracts, bank statements, ID scans and signed agreements pass through someone else's computer — usually with a free-tier page limit and a sign-up wall waiting at the end.

OnyxPDF works differently. Every tool runs locally in your browser using WebAssembly. **Your files never upload to a server — there is no server.** Nothing is stored, nothing is tracked, and there is nothing to leak. There is no account to create and nothing to pay: all 50 tools are free, because the site costs nothing to run.

Open a tool, drop your file in, download the result. That's it.

## Highlights

- **Real AES-256 encryption.** Protect PDF uses genuine AES-256 (via qpdf compiled to WebAssembly) — the same standard desktop tools use, not a weak permissions flag that any reader can ignore.
- **OCR in 7 languages.** Scanned documents become searchable, selectable text without the scan ever leaving your device.
- **Background removal, on-device.** The Remove Background tool runs the DIS IS-Net model locally in your browser. The model weights are Apache-2.0 licensed, and your photo is never sent to an AI server — because there isn't one.
- **Passport Photo Maker.** Correct dimensions for common ID and visa photo requirements, with a print-ready sheet layout.
- **HEIC to JPG at full resolution.** iPhone photos converted without the quality loss most online converters quietly apply.

## Honest limits

A browser tool has real constraints, and we'd rather state them than hide them: compression of already-optimised PDFs has a quality trade-off, the Edit tool adds content on top of a PDF rather than rewriting its existing text, and very large files are limited by your device's memory. Where a tool has a limit, the tool page says so.

## How it works

- Static site hosted on GitHub Pages — no backend, no database, no running cost
- PDF and image processing happens in WebAssembly and JavaScript, entirely on your device
- Installable as a PWA, so the tools keep working like an app once loaded
- Tool pages are plain static pages with their own URLs, so each tool can be bookmarked and shared directly
